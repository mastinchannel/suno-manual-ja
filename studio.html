Chapter 03

Suno Studio 2.0の使い方まとめ

2026年8月13日、Studio 2.0 が公開されました。 チャットバー・MIDI・Wavetableシンセ・エフェクト・オートメーションが加わり、画面構成も変わっています。この章は Studio 2.0 を前提に書き直しています。旧Studio(1.x)の記事は公式ヘルプの「Studio Archive」に残っています。

Suno Studio 2.0とは(概要・動作環境)

Suno Studio は、AIによる音楽生成とDAW(Digital Audio Workstation)のマルチトラック編集を組み合わせた、ブラウザで使う制作環境です。Studio 2.0 では、オートメーション、エフェクト、MIDI、シンセ、そして自分専用のプラグインを作る機能が加わり、これまでの生成ワークフローを中心に据えたまま「本格的な制作環境」になりました。

Studioの利用には Premierプラン が必要です。音楽制作の経験がなくても使えるように、アイコンにカーソルを合わせると機能の説明(ツールチップ)が表示されます。

出典: Introducing Suno Studio 2.0 / Studio 2.0 is here(リリースノート)

動作環境(推奨スペック)

  • デスクトップ/ノートPC/タブレット(画面幅768px以上、スマートフォンは非対応)
  • SIMD対応CPU(SSE4.1 または Neon)、4GB以上のRAM
  • 推奨ブラウザ:最新版のGoogle Chrome(SafariはWeb MIDIに非対応のため、MIDI機器を使う場合は特にChromeを推奨)
  • インストール不要。オーディオインターフェースやMIDIコントローラーは、PC側で正しくドライバーが入っていればそのまま使えます
出典: Introducing Suno Studio 2.0(FAQ)

旧Studio(1.x)からの主な変更点

  • Context Bar → Chat Bar:StemのCover・Remixに使っていたバーが、会話で指示できるチャットバーになりました(詳しくはStudio Chat)。
  • Transportの位置:メトロノーム・再生・一時停止・ループ・Follow Playhead・時計表示・テンポ・拍子の設定が、タイムラインの上に移動しました。一般的なDAWに近い配置です。
  • Alternates → Take Lanes:1回の生成で2クリップ作られる点は同じです。クリップ下部をクリックすると、タイムラインへの確定・プレビュー破棄・上下矢印での候補切り替えができます。
  • 1.xのプロジェクト:Studio 1.xは2026年9月上旬に提供終了の予定と案内されていました。1.xのプロジェクトは2.0でも開けますが、新しいバージョンとして保存され、2.0で加えたエフェクト・オートメーション・MIDIなどは1.xに戻せません。
出典: Introducing Suno Studio 2.0

Studioでできること・できないこと

  • アップロードできるファイル:WAV・MP3・MIDI
  • 既存のSuno曲を開く:Libraryで曲の「…」→ Edit → Open in Studio
  • 他のDAWとの関係:Studioで作ったパート・サンプル・Stemを書き出して既存のDAWで使えますが、DAWとの直接同期やプラグインホスト連携はありません
  • VST・Audio Unitsプラグインは使えません。代わりに内蔵エフェクト・シンセと、チャットで作る自作プラグインを使います
出典: Introducing Suno Studio 2.0(FAQ)

StudioでLibraryを使う

Sunoのライブラリは、画面右側のドック(4 キーまたはヘッダーの Library ボタンで開閉)として表示されます。All Songs・Liked・Stems・Uploads・Workspaces・Studio Projects を切り替えられ、日付ごとに並んだ一覧を絞り込み・検索できます。

  • 行をクリック、または上下矢印キーで順に試聴できる
  • 曲をダブルクリックすると Song Details が開き、Stemsタブ(Auto / Split from Mix / Custom 抽出、Insert all)とNotesタブを使える
  • 曲をタイムラインにドラッグするとオーディオトラックに追加、チャットにドロップするとプロンプトに添付できる
  • 下部のミニプレーヤーはタイムラインと同時に再生できるので、プロジェクトに合うか確定前に確かめられる

表示状態(画面・フィルター・検索)はプロジェクトごとに記憶されます。

出典: Access your Library in Studio

Studio Chat(チャットバー)の使い方

Chat Bar(チャットバー、現在ベータ)は、Studioに普通の言葉で指示する入り口です。メニューを探さなくても、「make the drums punchier(ドラムをもっと力強く)」「add a moody synth pad under the chorus(サビの下にムーディーなシンセパッドを足して)」のように入力すると、Studioが変更を加えます。チャットはプロジェクトの内容と選択中の対象を理解し、手作業と同じ操作で編集します。

最初の指示を出す手順

  1. 画面中央の円形のスパークルアイコンをクリックするか、トラック/クリップを選択して Enter を押す
  2. 「add a laid-back bass line that follows the drums」のように入力する
  3. チャットが「Inspecting the tracks」などの短い状況表示を出しながら作業し、タイムラインに新しいベーストラックが生成される
  4. 完了すると、行った内容の説明と操作ボタンが表示される(Audition Take 2 で別テイクをその場で試聴し、気に入れば Commit。カスタムエフェクトを作った場合は Add to track)

指示があいまいなときは、チャットが勝手に推測せず「ベースはキックに合わせる? ハーフタイムにする?」のような選択式の質問を出して返答を待ちます。

知っておきたいポイント

  • すべて取り消せる:チャットの変更も自分の操作と同じ扱いなので、Cmd/Ctrl+Z で元に戻せます。
  • 選択中のものが対象:「make this louder」は選択中のトラックやクリップを指します。テンポなどのプロジェクト情報も踏まえて動きます。2026年9月の更新でBPMやテンポ変更も理解するようになりました。
  • 2つの表示:タイムライン上に浮かぶクイック入力用の Magic Bar と、左側の履歴確認用の チャットパネル があり、1 キーで切り替えられます。どちらも同じ会話です。
  • 会話はプロジェクトごとに保存:翌日も前日の文脈から続けられます。設定メニューから履歴を消すこともできます。

チャットでできること

  • プロジェクトの確認(トラック一覧、トラックの中身・設定、選択範囲、テンポ)
  • トラック・クリップの編集(手作業と同じ構造的な編集)
  • 音楽の生成(MIDIパートの作曲、選択範囲の別テイク生成)
  • エフェクトの作成(言葉で説明した音のカスタムプラグインを作る。時間のかかる作成はバックグラウンドで続く)
  • 画面の移動(トラックのエフェクトラックを開くなど、必要な画面を開いてくれる)
出典: Studio Chat / Updates to Suno Studio(リリースノート)

MIDIとWavetableシンセの使い方

Studio 2.0 では MIDI が使えるようになりました。MIDIクリップには「音」ではなく「音符」(音程・タイミング・強さ)が入っていて、トラックに読み込んだ楽器がそれを音に変えます。あとから音符を直したり、楽器を差し替えたりできるのが特長です。

MIDIトラックを作る

  1. 最後のトラックの下にある + Track をクリック、または Shift+T
  2. 「Add a track」で MIDI を選ぶ(M キーでも選択可)
  3. 新しいトラックには Wavetable シンセが最初から読み込まれている。プリセットを選べば音色を変えられる
  4. 演奏用キーボード(Cmd/Ctrl+K)を開くか、MIDIコントローラーをつないで演奏する

音符を手で入力するには、MIDIトラックの空白部分を選択して + Add Midi Clip でクリップを作り、クリップのヘッダーをダブルクリックしてピアノロールを開き、ピアノロール内をダブルクリックして音符を置きます。

ピアノロールでの編集

  • 音符をドラッグで移動、端をドラッグで長さ変更(Alt キーを押すと選択/描画モードを切り替え)
  • 音符を選んで Shift+Q でグリッドにクオンタイズ
  • 右下の Automation トグルでベロシティパネルを開き、音の強さを調整
  • クリップ下部のキー/スケール設定(scale assist)で、調に合う行をハイライト

Musical Typing(パソコンのキーボードで演奏)

MIDIコントローラーがなくても、パソコンのキーボードを鍵盤として使えます。A〜; が白鍵、W E T Y U O P が黒鍵、Z/X でオクターブ上下、C/V でベロシティ上下です。シンセパネルにはアルペジエーターやコードモードもあり、弾いたコードはタイムラインにドラッグするとMIDIクリップになります。録音するにはトラックを録音待機にして Shift+R を押します。

外部MIDIコントローラー・MIDI Learn

  • ブラウザのWeb MIDI機能で接続するため、ドライバーのインストールは不要(初回にブラウザのMIDI許可が必要)
  • MIDIトラックのヘッダーにある入力セレクターで、どの機器をどのトラックに使うか選ぶ
  • MIDI Learn:プラグインや楽器のつまみを右クリック → MIDI Learn → ハードウェアのつまみを動かすと割り当てられる(プロジェクトに保存され、1つのつまみで複数パラメーターも操作可)
  • トランスポート操作:割り当てのないCC 115〜118 は再生・停止・録音・ループとして動作

オーディオとMIDIの変換

オーディオクリップをMIDIトラックにドラッグすると音符に変換(採譜)できます。逆に、チャットからMIDIをもとにしたオーディオの「カバー」を生成することもできます。2026年9月の更新で、MIDI→オーディオ変換の速度と精度が上がり、チャットにMIDIクリップから新しいオーディオStemを作らせたり、Suno外で作ったMIDIファイルをアップロードしたりできるようになりました。

出典: MIDI in Studio / Suno Studio: Improved MIDI and more(リリースノート)

Wavetableシンセ

Studioの主力楽器が Wavetable シンセです。単一周期の波形を並べたテーブルを移動しながら音を作る方式で、太いベース、鋭いリード、厚いパッド、プラック、ゆっくり変化する質感まで1台でカバーします。

  • 構成:オシレーター2基(Warp・Unison・Spread付き)、サブオシレーター、マルチモードフィルター(Cutoff・Resonance)、エンベロープ4基、LFO 3基、モジュレーションマトリクス、モノ/ポリ切替とグライド
  • 808系ベース・Reeseベース・アシッド・パッド・プラック・レトロゲーム音などのファクトリープリセット付き
  • デバイス左下をクリックで簡易表示、右上の Resize またはヘッダーのダブルクリックでフルエディター
  • 音作りはチャットでも可能:トラックを選んで Enter を押し、「create a glassy synth pad that evolves into a wobble」のように説明すると、パッチを組んでくれる
  • 自作プリセットはアカウントに保存され、他のプロジェクトでも使える。自分のウェーブテーブルのアップロードや、タイムライン上のオーディオをウェーブテーブルとして取り込むことも可能
出典: The Wavetable Synth in Studio

クリップ編集・Take Lanes・録音

クリップを編集する

クリップをダブルクリックすると、下部に Arrangement Editor が開きます(MIDIクリップの場合はピアノロール)。下部のフッターバーに、クリップの種類に応じた操作がまとまっています。

  • オーディオクリップ:Loop、Reverse、Stretch(ワープの切替とマーカーのプリセット)、Quantize、Pitch(移調)、Formant、Speed(0.5x・2x)、Volume
  • MIDIクリップ:Loop、Quantize、Key/Scale assist、View、ノートプレビュー、Automation
  • Info:Styles・Lyrics・Metadataの3タブを表示

タイムライン上では、Cmd/Ctrl+E で再生位置で分割、0 で選択クリップを無効化(暗くなり無音になる)できます。Stretch をオンにしてダブルクリックでワープマーカーを置き、ドラッグでタイミングを調整します。2026年10月の更新で、Shift+クリック+ドラッグでクリップをテンポに合わせて伸縮できるようになり、フェードにも指数・対数カーブが選べるようになりました。

出典: Editing Clips in Studio / Improvements to Studio(リリースノート)

Take Lanes(テイクレーン)で聴き比べる

生成のたびに2つのバージョンができ、それが Take Lanes に並びます(3 キーで表示切替)。

  • 試聴:レーンをクリックするとその場でソロ再生。新しい生成の最初のテイクは自動で試聴される
  • 評価:各クリップに高評価/低評価。低評価では「音質」「タイミング」「複数のStemが混ざっている」から理由を選べ、最後を選ぶとStem分離を提案される(評価はモデルの品質改善に使われる)
  • 確定:Commitボタン(または Enter)で、そのテイクをメイントラックに非破壊で反映

Replace section で差し替えた場合も、元の音声はテイクレーンに残るので失われません。

出典: Take Lanes in Studio

録音する

オーディオやMIDIをタイムラインに直接録音できます。Studioならではの使い方として、録音した鼻歌をストリングスに、シンセで弾いたコードをアコースティックギターに変える、といったこともできます。

  1. トラックの A を選んで録音待機にし、オーディオトラックなら入力、MIDIトラックなら機器を選ぶ
  2. タイムライン上部の赤い録音ボタン、または Shift+R で録音開始
  3. 停止ボタン(またはスペースキー)で停止すると、テイクがすぐタイムラインに置かれる

録音ボタンにカーソルを合わせると、1・2・4小節の Count-In や Pre-Roll を設定できます。音が遅れて録れる(レイテンシー)場合は、録音ボタンから calibrate を選ぶと、クリック音で遅延を測定して補正します。MIDIの録音はループ再生のたびにテイクとして重なり、オーディオと同じように良い部分を組み合わせられます。

出典: Recording in Studio / MIDI in Studio

Remove FX(Get Dry)

音に焼き込まれたリバーブやディレイなどをAIで取り除き、ドライな音にする機能です。オーディオクリップのヘッダーを右クリック → Remove FX を選ぶと、ドライ版が新しいテイクレーンに追加されて自動で試聴されます。気に入れば Commit します。

出典: Remove FX (Get Dry) in Studio

StudioでStemを分離する

オーディオクリップを右クリック → Split Stems → 分離方法(Split from Mix・Advanced Split を含む)を選んで Extract します。分離したパートはタイミングをそろえた新しいトラックに置かれるので、元のトラックはミュートして使います。各モードのクレジットは曲を作る:Stem分離を参照してください。

出典: How do I get stems? / Introducing Suno Studio 2.0

エフェクト・自作プラグイン・オートメーション

内蔵エフェクト

Studio 2.0 には、ミックスと音作りの基本をカバーするリアルタイムエフェクトが入っています。トラックを選んで Add effect から追加します。

  • Compressor:音量差の制御。サイドチェインに対応し、ポンピングやダッキングも可能
  • EQ:周波数を持ち上げたりカットしたりして、ミックス内の居場所を作る
  • Reverb / Convolution:空間の広がり(Convolutionは実際の空間を収録したインパルスレスポンスを使う)
  • Delay:テンポに合わせたやまびこ効果
  • Distortion:歪みで荒さや迫力を足す
  • Gate:ノイズを切り、演奏を引き締める

エフェクトはトラックごとに順番どおりにつながった「チェーン」になっていて、ドラッグで並べ替え、バイパス、展開して細かく調整、プリセットの保存・読み込みができます。プラグインはドラッグでトラック間を移動・コピーでき、Cmd/Ctrl+D で同じトラック上に複製できます。

トラックのフェーダー(音量)・パン・Mute・Solo といった基本のミックス操作も引き続き使えます。EQは小さな調整(±3dB程度)から始めるのが無難です。

チャットで自分専用のプラグインを作る

  1. Studioでプロジェクトを開き、チャットバーを開く
  2. 「a warm tape delay that wobbles slightly(少し揺れる温かいテープディレイ)」のように欲しいエフェクトを説明する
  3. Studioがプラグインを作る。パラメーターの確認を求められたら Build It! か Adjust Something First を選ぶ
  4. 「make the wobble slower」のように会話で調整し、気に入ったらライブラリに保存して、どのプロジェクトのどのトラックにもドラッグで使う

自作プラグインも内蔵エフェクトと同じエンジンで動き、プリセット・オートメーション・MIDI Learnに対応します。公開時点ではプラグインの作成にクレジットは不要ですが、将来クレジット制が導入される可能性があると案内されています。

出典: Audio Effects and Plugins in Suno Studio / Updates to Suno Studio(リリースノート)

オートメーション

パラメーターを曲の途中で変化させる機能です。サビに向けた音量の盛り上げ、ドロップ前のフィルタースイープ、ボーカル末尾だけのディレイなどに使います。トラックの音量・パンと、ほぼすべてのエフェクト/プラグインのパラメーターを自動化できます。

  1. Shift+A(またはAutomationボタン)でフォーカス中トラックのオートメーション表示を開く
  2. つまみを右クリック → Automate でレーンを作る
  3. レーンをダブルクリックでポイントを追加、ポイントのドラッグで移動、ポイント間の線をドラッグでカーブにする
  4. 複数ポイントを選んで矢印キーで微調整

自動化されたつまみは緑の枠で表示され、再生中の実際の値が見えます。オートメーションは書き出した曲とStemにも反映されます。削除はパラメーターを右クリック → Delete automation lane です。最初は1トラックの音量から試すと覚えやすいです。

出典: Automation in Studio

Suno Studioからのエクスポート方法

タイムライン右上の Export ドロップダウンから書き出します。

  • Full Song:プロジェクト全体のミックス
  • Selected Time Range:タイムラインで選択した範囲のみ
  • Multitrack:全トラックをStemとして個別に書き出し(他のDAWでのミックス用)

書き出し形式は32bit WAV または MP3 です。個別のクリップは、右クリック → Download .WAV で書き出せます。

MIDIの書き出し: Stemパネルで抽出したStemを選び、Get MIDI(10クレジット)を選ぶと、他のDAWに読み込めるMIDIファイルが作られます。

ダウンロード上限との関係: 2026年9月3日から通常の曲ダウンロードには月ごとの上限ができましたが、Premier会員がStudioで行う作業(Stemやサンプルの書き出しなど)は上限の対象外と案内されています(ダウンロード上限を参照)。
